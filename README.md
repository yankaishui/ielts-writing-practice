# IELTS Writing Task 2

**[在线练习（建议用电脑）](https://writing.yankaishui.com/)** · [IELTS Practice 系列](https://github.com/yankaishui)

备考时最折磨我的就是写作。

强迫自己坐下来，专心写满四十分钟，再发给 AI 纠错、点评。收到回复，扫一眼，关掉。下一篇，同样的错误继续犯，想学的句式忘了，该展开的观点还是没展开。

所以这个工具主要想解决的是：**写完之后怎么办。**

可以从题库选题，也可以输入自己的题目。没时间写整篇，就单独练开头、主体段或结尾。建议用电脑，手机写长文不方便，输入法自动纠错也容易掩盖原本会犯的错误。

写完后，复制工具生成的指令和作文，发给你自己使用的 AI，再把返回的反馈导入。原本看完就关掉的点评，会整理成可以回来继续用的复盘内容：

- 四项预估评分，看看哪一项拖了后腿。
- 八维能力图，把观点展开、具体论证等问题分开看。
- 对照原文看哪里有问题、为什么、可以怎么改。
- 收藏值得留下的表达，下次写作前回来复习。
- 找到下一篇最应该优先练的问题。

反复出现的语言错误会归到“我的易错点”。作文和反馈会留下来，也可以回来挑一段继续修改，不必每次都从另一篇四十分钟的作文开始。

练习记录保存在当前电脑的浏览器里，建议定期导出备份。AI 评分只作练习参考，不是官方成绩。

这个工具尤其想帮助目前在 5.5—6.5 分附近、愿意自己写，但不知道怎么复盘的同学。第一次使用，可以先看反馈页面里的“演示”视频。

## 本地运行

使用 Node.js 22.12 或更高版本：

```sh
npm ci
npm run dev
```

打开终端显示的本地地址。工具本身不调用 AI API，也不需要配置 API Key；反馈需要从你使用的外部 AI 获取后导入。

## 检查和构建

```sh
npm test
npm run build
```

构建结果在 dist/。部署到静态托管时，需要将前端路由回退到 index.html。浏览器测试位于 tests/；先启动本地服务，再按测试文件中的要求运行。

## 数据保存

作文、反馈、收藏和练习记录保存在当前浏览器的 localStorage 中。请在设置中定期导出备份；更换浏览器或域名时，可以导出后再导入。把作文粘贴到外部 AI 时，该服务会接收你发送的内容。
